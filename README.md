# My Anime Log (Full-Stack Web Application)

เว็บแอปพลิเคชันเก็บบันทึกรายการอนิเมะส่วนตัว พัฒนาขึ้นเพื่อเรียนรู้การทำงานแบบ Full-Stack Web Development ตั้งแต่ระดับพื้นฐาน

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (DOM Manipulation, Fetch API)
- **Backend:** Node.js, Express.js (REST API Architecture)
- **Database:** SQLite3

## Features
- **Create:** บันทึกชื่ออนิเมะใหม่ลงในฐานข้อมูล
- **Read:** ดึงรายการอนิเมะทั้งหมดมาแสดงผลบนหน้าเว็บ
- **Delete:** ลบรายการอนิเมะออกจากฐานข้อมูล

## How to Run Locally
1. Clone repository นี้ลงเครื่อง
2. เปิด Terminal แล้วพิมพ์ `npm install` เพื่อติดตั้ง dependencies
3. พิมพ์ `node server.js` เพื่อสั่งรันเซิร์ฟเวอร์
4. เข้าไปที่ `http://localhost:3000` ผ่านเว็บเบราว์เซอร์
